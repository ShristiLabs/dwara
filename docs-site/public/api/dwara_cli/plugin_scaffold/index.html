Plugin scaffolding (DW-057).

dwara plugin new generates a new proxy-wasm plugin project from a template: a Rust crate targeting wasm32-wasip1 that implements the proxy-wasm ABI and hooks dwara’s phase contract.

The default scaffold includes:

  • Cargo.toml (targeting wasm32-wasip1, depending on proxy-wasm)
  • src/lib.rs (a minimal proxy-wasm filter with the phase callbacks)
  • dwara.yaml (a minimal gateway config that loads the plugin)
  • README.md (build + run instructions)

DW-166 (#284): --template <name> scaffolds from one of the four example plugins instead (see crate::plugin_templates): the example’s source is vendored with the crate name substituted, so the scaffolded project carries the example’s tests (host-runnable via the fake host in src/abi.rs) and builds with zero dependencies.
