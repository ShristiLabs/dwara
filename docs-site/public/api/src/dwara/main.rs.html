1//! Gateway server binary.
2//!
3//! M1 role: bind listeners, proxy traffic off the published config
4//! snapshot (DW-009), keep that snapshot hot (DW-006), and terminate or
5//! pass through TLS (DW-007). Every request is served by
6//! [`dwara_core::proxy::handle`] against the generation pair (snapshot +
7//! upstream registry) current at request time; a reload swaps the pair
8//! under the accept loop without ever interrupting accept, and in-flight
9//! requests keep their old pair alive until they complete.
10//!
11//! Runtime controls (environment):
12//! - `DWARA_BIND`: when set, overrides the config listeners with a
13//!   single cleartext HTTP listener on that address (test/dev escape
14//!   hatch; e.g. `127.0.0.1:8080`). When unset, the gateway binds every
15//!   listener defined by the config snapshot.
16//! - `DWARA_CONFIG`: path to the gateway YAML config, default `./dwara.yaml`.
17//!   Startup fails (exit code 1) if the file cannot be read or does not
18//!   validate; every validation issue is printed.
19//! - `DWARA_STATE_DB`: path to a SQLite state store (DW-018). When set,
20//!   the gateway opens/creates the store at startup and seeds consumers
21//!   and credentials from the config into it (hashed at seed time; see
22//!   `store::sync_consumers_from_config`). When unset (the default), the
23//!   gateway runs purely on config — credentials hashed in memory at
24//!   startup. The authenticator (DW-019) consults the store when it is
25//!   set and config credentials otherwise.
26//! - `DWARA_SHUTDOWN_TIMEOUT_SECS`: graceful-drain budget on SIGTERM/SIGINT,
27//!   default 10. In-flight requests that exceed the budget are dropped when
28//!   the process exits.
29//! - `DWARA_WORKER_THREADS` (#273): number of tokio async worker threads,
30//!   default `available_parallelism()`. Set to a lower value in containers
31//!   with cgroup CPU limits to avoid oversubscription.
32//! - `DWARA_MAX_BLOCKING_THREADS` (#273): size of the blocking thread pool,
33//!   default 512. Raise if `spawn_blocking` is used heavily.
34//! - `DWARA_ACCEPTORS_PER_LISTENER` (#271): number of concurrent acceptor
35//!   tasks per listener, default 1. Set to the number of CPU cores to
36//!   parallelize connection acceptance and keep all tokio workers fed.
37//! - `DWARA_POOL_SHARDS`: number of hyper-util client pool shards per
38//!   upstream, default 1. Set to the number of tokio workers to reduce
39//!   pool-lock contention under high concurrency (each shard has its own
40//!   `Mutex<PoolInner>`). The connection cap is shared across shards via
41//!   `Arc`, so the total cap is not multiplied.
42//! - `DWARA_LOG` (DW-021): RUST_LOG-syntax filter for the tracing
43//!   subscriber, default `dwara=info`. Output is JSON on STDOUT (spans,
44//!   structured logs, and the per-request `dwara::access` access-log
45//!   lines).
46//! - `DWARA_ACCESS_LOG_SAMPLE` (DW-021): fraction of non-error access
47//!   lines emitted, 0.0-1.0, default 1.0; 5xx responses are always
48//!   logged (see dwara-core's observability docs).
49//! - `DWARA_OTLP_ENDPOINT` (DW-021, #126): base OTLP collector endpoint
50//!   (e.g. `http://collector:4318`; `/v1/traces` is appended). Compiled
51//!   into every build (no cargo feature; the opentelemetry stack is an
52//!   unconditional dependency). With the variable set, the root/phase
53//!   spans export over http/protobuf and are flushed (bounded) on the
54//!   SIGTERM/SIGINT drain path; the variable unset = one INFO line and
55//!   no exporter.
56//! - `DWARA_ADMIN_DEV` (DW-022): "1" serves the admin API as PLAINTEXT
57//!   on 127.0.0.1 — DEV ONLY, refuses to start for a non-loopback
58//!   admin bind, and must never be set in production (mTLS is the
59//!   admin surface's only authentication). Default: unset = mTLS-only.
60//!   See the `dwara-admin` crate docs for the endpoint set.
61//! - `DWARA_CREDENTIAL_PEPPER` (#124): per-deployment SECRET that peppers
62//!   every NEW stored API-key/Basic hash (`hmac-sha256:<hex>`), so a
63//!   state-DB leak alone cannot verify guesses. Resolved at startup
64//!   through the SecretSource extension seam (EnvSecretSource for the
65//!   OSS edition; a managed backend may be swapped in separately).
66//!   Unset = legacy-only mode (legacy `sha256:` entries keep verifying;
67//!   peppered entries fail closed with one ERROR log). An EMPTY value is
68//!   treated as unset. A SET-but-unreadable value refuses startup. The
69//!   value is never logged.
70//! - Protocol hardening (DW-023, feature analysis 4.20): every serving
71//!   surface (data-plane listeners AND the admin listener) applies the
72//!   knob set documented in dwara-core's `hardening` module — HTTP/1
73//!   header-count / read-buffer caps and the slowloris header-read
74//!   timeout (`DWARA_HTTP1_MAX_HEADERS`, `DWARA_HTTP1_MAX_BUF_KIB`,
75//!   `DWARA_HTTP1_HEADER_TIMEOUT_MS`), HTTP/2 stream/window/send-buffer
76//!   caps (`DWARA_H2_MAX_CONCURRENT_STREAMS`, `DWARA_H2_STREAM_WINDOW_KIB`,
77//!   `DWARA_H2_CONNECTION_WINDOW_KIB`, `DWARA_H2_MAX_SEND_BUF_KIB`), and
78//!   the inbound request-body inactivity gap
79//!   (`DWARA_REQUEST_BODY_TIMEOUT_MS`, 0 disables). CL+TE smuggling needs
80//!   no knob: hyper 1.x rejects such requests and the gateway rebuilds
81//!   every forwarded request from parsed parts (never raw passthrough);
82//!   both properties are pinned by dwara-bin's protocol-hardening tests.
83//!
84//! Shutdown: SIGTERM/SIGINT stop accepting on every listener, each
85//! listener flushes its kernel backlog (established connections are
86//! served), HTTP connections drain via hyper graceful shutdown, and
87//! in-flight passthrough and L4 splices drain via the process-wide
88//! SpliceDrain (#175, REL-04): the process waits for in-flight byte
89//! relays to complete up to the shutdown deadline. The gateway does NOT
90//! terminate TLS in passthrough mode, so it cannot emit a TLS
91//! close_notify alert (no session keys); the drain is a bounded wait for
92//! the peer to close or the bidirectional copy to return. Whatever
93//! remains at the deadline is force-closed by process exit.
94//! With the `otlp` feature, the exporter flush is the LAST bounded step
95//! before exit (see the DWARA_OTLP_ENDPOINT bullet).
96//!
97//! Zero-downtime upgrade (DW-049): SIGUSR2 spawns a new copy of the
98//! binary. Both the old and new processes bind the same ports with
99//! `SO_REUSEPORT` (the kernel load-balances accepts); the new process
100//! signals READY over a Unix domain socket once it is accepting, the old
101//! process then runs the SAME drain sequence as SIGTERM and exits. The
102//! hand-off has no refused connections and no reset connections (the new
103//! process is already accepting before the old stops). A failed upgrade
104//! (spawn error or READY timeout) logs and keeps the old process running.
105//! Operator trigger: `dwara upgrade` (CLI) sends SIGUSR2 to the PID in
106//! the PID file. Relevant env vars: `DWARA_PID_FILE` (PID file path),
107//! `DWARA_UPGRADE_BINARY` (new binary path; default current exe),
108//! `DWARA_UPGRADE_READY_TIMEOUT_SECS` (READY wait budget, default 30).

154fn shutdown_timeout() -> Duration {
155    std::env::var("DWARA_SHUTDOWN_TIMEOUT_SECS")
156        .ok()
157        .and_then(|v| v.parse::<u64>().ok())
158        .map(Duration::from_secs)
159        .unwrap_or(Duration::from_secs(DEFAULT_SHUTDOWN_TIMEOUT_SECS))

162/// Build the tokio runtime from env vars (#273).
163///
164/// - `DWARA_WORKER_THREADS`: number of async worker threads (default:
165///   `available_parallelism()`). Set to a lower value in containers with
166///   cgroup CPU limits to avoid oversubscription.
167/// - `DWARA_MAX_BLOCKING_THREADS`: size of the blocking thread pool
168///   (default: 512, the tokio default). Raise if `spawn_blocking` is used
169///   heavily (e.g., nano-services).
170fn build_runtime() -> tokio::runtime::Runtime {
171    let workers = std::env::var("DWARA_WORKER_THREADS")
172        .ok()
173        .and_then(|v| v.parse::<usize>().ok())
174        .filter(|n| *n > 0)
175        .unwrap_or_else(|| {
176            std::thread::available_parallelism()
177                .map(|n| n.get())
178                .unwrap_or(1)
179        });
180    let max_blocking = std::env::var("DWARA_MAX_BLOCKING_THREADS")
181        .ok()
182        .and_then(|v| v.parse::<usize>().ok())
183        .filter(|n| *n > 0)
184        .unwrap_or(512);
185    tokio::runtime::Builder::new_multi_thread()
186        .worker_threads(workers)
187        .max_blocking_threads(max_blocking)
188        .thread_name("dwara-worker")
189        .enable_all()
190        .build()
191        .expect("failed to build tokio runtime")
192}

194fn main() -> Result<(), Box<dyn std::error::Error + Send + Sync>> {
195    let runtime = build_runtime();
196    runtime.block_on(async_main())
197}

199async fn async_main() -> Result<(), Box<dyn std::error::Error + Send + Sync>> {
200    // Observability init (DW-021): JSON on STDOUT, filtered by DWARA_LOG
201    // (RUST_LOG syntax; default dwara=info). Installed FIRST so startup
202    // logs flow through the same pipeline as request logs.
203    //
204    // #126: with the `otlp` feature, DWARA_OTLP_ENDPOINT additionally
205    // bridges the span tree into an OTLP exporter — the provider must be
206    // built BEFORE the subscriber (the bridge is a subscriber layer), so
207    // the status line is logged after init, not here. The composition is
208    // registry + EnvFilter + JSON fmt (identical to the fmt()-builder
209    // form) so the OTLP layer can join the chain when compiled in;
210    // feature OFF compiles the exact same subscriber as before.
211    //
212    // DW-097: with the `console` feature, DWARA_CONSOLE=1 additionally
213    // spawns the tokio-console gRPC server (default 127.0.0.1:6669) —
214    // the `tokio-console` CLI connects to it for live async task
215    // diagnostics. The console layer joins the subscriber chain the
216    // same way as OTLP; feature OFF compiles the exact same subscriber.
217    let otlp = otlp::Otlp::from_env();
218    // DW-097: build the console layer when the feature is compiled in
219    // AND DWARA_CONSOLE is set (unset = inert, no server spawned).
220    let console_enabled = std::env::var("DWARA_CONSOLE").is_ok();
221    let console_layer: Option<_> = if console_enabled {
222        Some(
223            console_subscriber::ConsoleLayer::builder()
224                .server_addr(([127, 0, 0, 1], 6669))
225                .spawn(),
226        )
227    } else {
228        None
229    };
230    let filter =
231        EnvFilter::new(std::env::var("DWARA_LOG").unwrap_or_else(|_| "dwara=info".to_string()));
232    let subscriber = tracing_subscriber::registry()
233        .with(filter)
234        .with(tracing_subscriber::fmt::layer().json().with_target(true));
235    let subscriber = subscriber.with(otlp.layer());
236    let subscriber = subscriber.with(console_layer);
237    subscriber.init();
238    otlp.log_status();
239    if console_enabled {
240        tracing::info!(
241            code = "console_enabled",
242            "tokio-console listening on 127.0.0.1:6669 (connect with `tokio-console`)"
243        );
244    }
245    tls::install_aws_lc_rs_provider();
246
247    // DW-111: FIPS 140-3 mode startup self-test. The aws-lc-rs provider
248    // is installed as the process-default in every build (the regular
249    // install above). In Enterprise builds (the `ent` cargo feature),
250    // FIPS enforcement is active: the self-test must pass or the gateway
251    // refuses to boot. In OSS builds the self-test runs for attestation
252    // on /healthz but does not gate startup. The attestation is logged
253    // at startup and surfaced on /healthz.
254    {
255        dwara_core::fips::install_fips_provider();
256        let attestation = dwara_core::fips::fips_self_test();
257        if dwara_core::fips::FipsMode::current().is_enabled() && !attestation.self_test_passed {
258            tracing::error!(
259                code = "fips_self_test_failed",
260                provider = %attestation.provider,
261                "FIPS self-test failed: the process-default crypto provider is not the \
262                 FIPS-validated aws-lc-rs provider (got '{}'); refusing to start in FIPS mode",
263                attestation.provider
264            );
265            std::process::exit(1);
266        }
267        if attestation.enabled {
268            tracing::info!(
269                code = "fips_mode_active",
270                provider = %attestation.provider,
271                self_test_passed = attestation.self_test_passed,
272                timestamp = attestation.timestamp,
273                "FIPS 140-3 mode active: aws-lc-rs FIPS provider installed and self-test passed"
274            );
275        }
276    }
277
278    let config_path = PathBuf::from(
279        std::env::var("DWARA_CONFIG").unwrap_or_else(|_| DEFAULT_CONFIG_PATH.to_string()),
280    );
281
282    let source = FileConfigSource::new(&config_path);
283    // DW-044: the process's event bus exists BEFORE the first publish, so
284    // the startup publish's `config_published` event is queued for the
285    // deliverer spawned below (bounded queue; overflow drops and counts,
286    // never blocks startup).
287    let event_bus = Arc::new(dwara_core::events::EventBus::new());
288    let state = Arc::new(ConfigState::with_event_bus(Arc::clone(&event_bus)));
289
290    // Startup load: a gateway that boots with a bad config must not serve at
291    // all. Print every issue, exit non-zero.
292    let gateway = match source.load().await {
293        Ok(g) => g,
294        Err(err) => {
295            tracing::error!(
296                code = "startup_config_load_failed",
297                "startup config load failed for {}: {err}",
298                config_path.display()
299            );
300            std::process::exit(1);
301        }
302    };
303    let info = match state.compile_and_publish(&gateway) {
304        Ok(info) => info,
305        Err(err) => {
306            tracing::error!(
307                code = "startup_config_invalid",
308                "startup config invalid for {}: {err}",
309                config_path.display()
310            );
311            std::process::exit(1);
312        }
313    };
314
315    // DW-032: enterprise license gate. Built from the config's `license`
316    // block at startup; the gate controls access to enterprise features
317    // (Redis rate limiter, config convergence, etc. — not yet
318    // implemented; the gate provides the check mechanism). The public
319    // key is NEVER in the YAML — it comes from the
320    // DWARA_LICENSE_PUBLIC_KEY env var (or the compiled-in dev key when
321    // unset), so an operator cannot substitute their own key to forge a
322    // license. When the `ent` cargo feature is NOT compiled in, the
323    // block is accepted but inert (the gate is always none()).
324    let license_gate = build_license_gate(&gateway);
325
326    // DW-111: FIPS mode license assertion. A license that carries the
327    // `fips` feature claim REQUIRES the gateway to be running in FIPS
328    // mode. When the license requires FIPS but the gateway is not built
329    // with the `ent` cargo feature (whose FIPS enforcement is active),
330    // refuse to start (exit 1). This is a
331    // config-time check: the assertion runs after the gate is built and
332    // before enterprise features engage.
333    if let Err(msg) = license_gate.assert_fips_compliance() {
334        tracing::error!(code = "license_fips_assertion_failed", "{msg}");
335        std::process::exit(1);
336    }
337
338    // Credential pepper (#124): resolved through the SecretSource
339    // extension seam BEFORE the state store is seeded (the pepper
340    // selects the stored-hash format for config-seeded keys) and handed
341    // to the dataplane, which threads the raw bytes down to the security
342    // domain (security must not import extensions — check_deps.py). The
343    // value is SECRET: it is never logged and never rendered.
344    const PEPPER_SECRET_NAME: &str = "DWARA_CREDENTIAL_PEPPER";
345    let credential_pepper: Option<Vec<u8>> = match EnvSecretSource.resolve(PEPPER_SECRET_NAME).await
346    {
347        Ok(Some(secret)) => {
348            let value = secret.expose();
349            if value.is_empty() {
350                tracing::warn!(
351                    code = "credential_pepper_empty",
352                    "{PEPPER_SECRET_NAME} is set but empty; running in legacy-only mode \
353                     (legacy sha256 stored hashes keep verifying, peppered entries fail closed)"
354                );
355                None
356            } else {
357                Some(value.as_bytes().to_vec())
358            }
359        }
360        Ok(None) => None,
361        // Set-but-unreadable (e.g. non-Unicode bytes): refuse startup.
362        // Silently degrading to legacy-only mode would quietly break
363        // verification of every peppered credential after a restart.
364        // The error text names the variable, never the value.
365        Err(err) => {
366            tracing::error!(
367                code = "credential_pepper_unreadable",
368                "secret {PEPPER_SECRET_NAME} could not be read: {err}; refusing to start"
369            );
370            std::process::exit(1);
371        }
372    };
373    if credential_pepper.is_some() {
374        tracing::info!(
375            code = "credential_pepper_active",
376            "credential pepper configured; new credential writes use the peppered \
377             hmac-sha256 stored-hash format"
378        );
379    }
380
381    // SEC-10: Pepper rotation. During a pepper rotation, the OLD
382    // pepper is kept in DWARA_CREDENTIAL_PEPPER_PREVIOUS so existing
383    // stored hashes (hmac-sha256:<hex> computed with the old pepper)
384    // keep verifying. New credential writes use the NEW pepper
385    // (DWARA_CREDENTIAL_PEPPER). Once all stored hashes have been
386    // re-hashed with the new pepper (via the state store's
387    // rehash-credential transition hook), the old pepper is removed.
388    // An empty previous pepper is treated as "no previous pepper"
389    // (same as unset).
390    const PEPPER_PREVIOUS_SECRET_NAME: &str = "DWARA_CREDENTIAL_PEPPER_PREVIOUS";
391    let credential_pepper_previous: Option<Vec<u8>> =
392        match EnvSecretSource.resolve(PEPPER_PREVIOUS_SECRET_NAME).await {
393            Ok(Some(secret)) => {
394                let value = secret.expose();
395                if value.is_empty() {
396                    None
397                } else {
398                    Some(value.as_bytes().to_vec())
399                }
400            }
401            Ok(None) => None,
402            Err(err) => {
403                tracing::warn!(
404                    code = "credential_pepper_previous_unreadable",
405                    "secret {PEPPER_PREVIOUS_SECRET_NAME} could not be read: {err}; \
406                 proceeding without a previous pepper (rotation window inactive)"
407                );
408                None
409            }
410        };
411    if credential_pepper_previous.is_some() {
412        tracing::info!(
413            code = "credential_pepper_rotation_window",
414            "credential pepper rotation window active; old pepper (DWARA_CREDENTIAL_PEPPER_PREVIOUS) \
415             verifies existing hashes, new pepper (DWARA_CREDENTIAL_PEPPER) is used for new writes. \
416             Rehash all credentials with the new pepper, then remove the previous pepper."
417        );
418    }
419
420    // Optional SQLite state store (DW-018): opened and seeded from the
421    // config when DWARA_STATE_DB is set. Held alive for the process
422    // lifetime and handed to the dataplane's authenticator (DW-019):
423    // credentials then resolve from the store's hot cache instead of
424    // in-memory config hashes. Unset = pure-config operation (default).
425    let state_store = match std::env::var("DWARA_STATE_DB") {
426        Ok(path) if !path.is_empty() => {
427            let store = match tokio::task::spawn_blocking({
428                let path = path.clone();
429                let gateway = gateway.clone();
430                // The seed closure needs its own copy while `main` keeps
431                // the original for the dataplane: hold the copy in a
432                // Zeroizing buffer so it is zeroized as soon as the seed
433                // finishes hashing (no plain copy outlives the work).
434                let pepper = credential_pepper.clone().map(Zeroizing::new);
435                move || {
436                    StateStore::open(std::path::Path::new(&path)).and_then(|s| {
437                        sync_consumers_from_config(
438                            &s,
439                            &gateway,
440                            pepper.as_deref().map(|p| p.as_slice()),
441                        )?;
442                        Ok(s)
443                    })
444                }
445            })
446            .await
447            {
448                Ok(inner) => inner,
449                Err(err) => {
450                    tracing::error!(
451                        code = "state_store_task_failed",
452                        "state store task failed for {path}: {err}"
453                    );
454                    std::process::exit(1);
455                }
456            };
457            match store {
458                Ok(store) => {
459                    tracing::info!(
460                        code = "state_store_opened",
461                        consumers = gateway.consumers.len(),
462                        "state store opened at {path} (schema v1, seeded consumers from config)"
463                    );
464                    Some(Arc::new(store))
465                }
466                Err(err) => {
467                    tracing::error!(
468                        code = "state_store_init_failed",
469                        "state store init failed for {path}: {err}"
470                    );
471                    std::process::exit(1);
472                }
473            }
474        }
475        _ => None,
476    };
477
478    // Listener set: DWARA_BIND overrides with one cleartext listener;
479    // otherwise bind every configured listener. SCALE-03 (#182): the
480    // same derivation runs on reload so the listener manager diffs the
481    // same set.
482    let configured: Vec<Listener> = configured_listeners(&state.snapshot());
483    if configured.is_empty() {
484        tracing::error!("config defines no listeners and DWARA_BIND is unset; nothing to serve");
485        std::process::exit(1);
486    }
487
488    let mut tls_states: BTreeMap<String, Arc<TlsTermination>> = BTreeMap::new();
489    // SCALE-03 (#182): TCP listeners (http, https, tcp) are bound and
490    // managed by the ListenerManager, which hot-reloads them on config
491    // changes. H3 (QUIC) listeners are collected separately here — they
492    // bind UDP sockets and run a QUIC accept loop, not a TCP accept loop.
493    // They reuse the TlsTermination cert material for the QUIC handshake.
494    let mut h3_listeners: Vec<(Listener, Arc<TlsTermination>)> = Vec::new();
495    // DP-01 (#234): UDP L4 listeners are collected separately — they
496    // bind a UDP socket and run the UdpDispatcher recv loop.
497    let mut udp_listeners: Vec<Listener> = Vec::new();
498    for l in &configured {
499        // DP-01 (#234): UDP listeners bind a UDP socket and run the
500        // UdpDispatcher. Collect them for separate binding below.
501        if l.protocol == ListenerProtocol::Udp {
502            udp_listeners.push(l.clone());
503            continue;
504        }
505        // DW-088: H3 listeners are handled separately (UDP/QUIC, not
506        // TCP). Skip them in the TCP bind loop.
507        if l.protocol == ListenerProtocol::H3 {
508            let tls_cfg = l.tls.as_ref().expect("validated h3 listener has tls");
509            let term = TlsTermination::build(tls_cfg).map_err(
510                |err| -> Box<dyn std::error::Error + Send + Sync> {
511                    format!("h3 listener {}: TLS build failed: {err}", l.name).into()
512                },
513            )?;
514            let term = Arc::new(term);
515            tls_states.insert(l.name.clone(), Arc::clone(&term));
516            h3_listeners.push((l.clone(), term));
517            tracing::info!(
518                code = "listening_h3",
519                addr = %format!("{}:{}", l.address, l.port),
520                listener = %l.name,

1083                    // same posture as the state store's advisory modes.
1084                    tracing::error!(
1085                        code = "analytics_open_failed",
1086                        path = %cfg.path,
1087                        "analytics store failed to open ({e}); serving WITHOUT analytics"
1088                    );
1089                    Vec::new()
1090                }
1091            }
1092        })
1093        .unwrap_or_default();
1094
1095    // DW-050: the GeoIP database — opened at startup when the config
1096    // carries a `geoip` block (fail LOUD, serve geo-UNKNOWN without
1097    // it), then a watcher polls the file's mtime and hot-swaps the
1098    // reader (no restart). In-flight lookups keep the reader they
1099    // loaded; the swap is atomic.
1100    let geoip_task = state.snapshot().gateway().geoip.as_ref().map(|cfg| {
1101        let path = cfg.path.clone();
1102        match dwara_core::security::geoip::GeoipDb::open(&path) {
1103            Ok(db) => {
1104                dp.set_geoip(std::sync::Arc::new(db));
1105                tracing::info!(
1106                    code = "geoip_open",
1107                    path = %path,
1108                    "geoip database open; geo rules evaluating"
1109                );
1110            }
1111            Err(e) => tracing::error!(
1112                code = "geoip_open_failed",
1113                path = %path,
1114                "geoip database failed to open ({e}); geo lookups resolve UNKNOWN"
1115            ),
1116        }
1117        let dp_geoip = Arc::clone(&dp);
1118        let mut shutdown_geoip = shutdown_rx.clone();
1119        tokio::spawn(async move {
1120            let mut last = std::fs::metadata(&path).and_then(|m| m.modified()).ok();
1121            loop {
1122                tokio::select! {
1123                    _ = tokio::time::sleep(std::time::Duration::from_secs(2)) => {
1124                        let mtime = std::fs::metadata(&path).and_then(|m| m.modified()).ok();
1125                        if mtime != last {
1126                            last = mtime;
1127                            match dwara_core::security::geoip::GeoipDb::open(&path) {
1128                                Ok(db) => {
1129                                    dp_geoip.set_geoip(Arc::new(db));
1130                                    tracing::info!(
1131                                        code = "geoip_reloaded",
1132                                        path = %path,
1133                                        "geoip database hot-reloaded"
1134                                    );
1135                                }
1136                                Err(e) => tracing::warn!(
1137                                    code = "geoip_reload_failed",
1138                                    path = %path,
1139                                    "geoip reload kept the previous reader ({e})"
1140                                ),
1141                            }
1142                        }
1143                    }
1144                    _ = shutdown_geoip.changed() => return,
1145                }
1146            }
1147        })
1148    });
1149    // SCALE-03 (#182): Listener hot-reload. The ListenerManager owns the
1150    // TCP listener tasks and hot-reloads them on config changes. It is
1151    // wrapped in an Arc<Mutex> so the reload driver task can call apply()
1152    // and the main shutdown path can call join_all().
1153    let timeout = shutdown_timeout();
1154    let hardening = Arc::new(HttpHardening::from_env());
1155    tracing::info!(
1156        code = "protocol_hardening",
1157        http1_max_headers = hardening.http1_max_headers,
1158        http1_max_buf_bytes = hardening.http1_max_buf_size,
1159        http1_header_timeout_ms = hardening.http1_header_read_timeout.as_millis() as u64,
1160        h2_max_concurrent_streams = hardening.h2_max_concurrent_streams,
1161        request_body_gap_ms = hardening
1162            .request_body_gap
1163            .map(|g| g.as_millis() as u64)
1164            .unwrap_or(0),
1165        "protocol hardening enabled (DW-023)"
1166    );
1167    let mut listener_manager = listener_manager::ListenerManager::new(
1168        Arc::clone(&state),
1169        Arc::clone(&dp),
1170        Arc::clone(&graceful),
1171        Arc::clone(&hardening),
1172        Arc::clone(&splice_drain),
1173        shutdown_rx.clone(),
1174        timeout,
1175    );
1176    // Bind the initial TCP listeners (http, https, tcp). H3 listeners
1177    // are already bound above and managed separately.
1178    listener_manager.apply(&configured, &mut tls_states).await;
1179
1180    // Certificate watcher: one watcher over every parent directory of a
1181    // terminate listener's cert/key files. SCALE-03 (#182): set up AFTER
1182    // the ListenerManager binds the initial listeners so TCP terminate
1183    // listeners' cert paths are included.
1184    let mut cert_dirs: Vec<PathBuf> = Vec::new();
1185    let mut cert_names: Vec<std::ffi::OsString> = Vec::new();
1186    for term in tls_states.values() {
1187        for p in &term.watched_paths {
1188            if let (Some(dir), Some(name)) = (p.parent(), p.file_name()) {
1189                if !cert_dirs.contains(&dir.to_path_buf()) {
1190                    cert_dirs.push(dir.to_path_buf());
1191                }
1192                if !cert_names.contains(&name.to_owned()) {
1193                    cert_names.push(name.to_owned());
1194                }
1195            }
1196        }
1197    }
1198    let cert_rx = if cert_dirs.is_empty() {
1199        mpsc::unbounded_channel().1
1200    } else {
1201        match spawn_file_watcher(cert_dirs, cert_names) {
1202            Ok(rx) => rx,
1203            Err(err) => {
1204                tracing::warn!(
1205                    "certificate watch unavailable ({err}); config reload still refreshes TLS"
1206                );
1207                mpsc::unbounded_channel().1
1208            }
1209        }
1210    };
1211
1212    let listener_manager = Arc::new(tokio::sync::Mutex::new(listener_manager));
1213
1214    let reload_listener_manager = Arc::clone(&listener_manager);
1215    let mut reload_tls_states = tls_states.clone();
1216    let reload_task = tokio::spawn(async move {
1217        let mut probes = dwara_core::active::ActiveProbes::new();
1218        probes.respawn(&reload_dp.registry(), &reload_state.snapshot());
1219        // DW-042: DNS discovery tasks — one per upstream that configures
1220        // `dns_discovery`. The resolver is shared across all tasks (one
1221        // resolver, many upstreams). Tasks are respawned on every reload,
1222        // mirroring ActiveProbes. The resolver uses the default public
1223        // name servers (system-config is off); a future enhancement
1224        // could read name servers from the config.
1225        let dns_resolver = Arc::new(dwara_core::dataplane::discovery::DnsResolver::new(&[]));
1226        let reload_obs = reload_dp.observability_arc();
1227        let mut discovery = dwara_core::dataplane::discovery::DiscoveryTasks::new();
1228        discovery.respawn(
1229            &reload_dp.registry(),
1230            &reload_state.snapshot(),
1231            Arc::clone(&dns_resolver),
1232            Arc::clone(&reload_obs),
1233        );
1234        let mut watcher_rx = watcher_rx;
1235        let mut shutting_down = reload_shutdown;
1236        loop {
1237            tokio::select! {
1238                _ = sighup.recv() => {
1239                    let mut lm = reload_listener_manager.lock().await;
1240                    reload(&reload_state, &reload_dp, &source, "sighup", &reload_tls, &mut probes, &mut discovery, &dns_resolver, &reload_obs, &mut lm, &mut reload_tls_states).await;
1241                }
1242                maybe_event = watcher_rx.recv() => {
1243                    let Some(()) = maybe_event else { break };
1244                    tokio::select! {
1245                        _ = tokio::time::sleep(RELOAD_DEBOUNCE) => {}
1246                        _ = shutting_down.changed() => return,
1247                    }
1248                    while watcher_rx.try_recv().is_ok() {}
1249                    let mut lm = reload_listener_manager.lock().await;
1250                    reload(&reload_state, &reload_dp, &source, "file-watch", &reload_tls, &mut probes, &mut discovery, &dns_resolver, &reload_obs, &mut lm, &mut reload_tls_states).await;
1251                }
1252                _ = shutting_down.changed() => return,
1253            }
1254        }
1255    });
1256
1257    // Certificate hot-reload driver: debounce, then rebuild every
1258    // terminate listener from the current snapshot's TLS config.
1259    let cert_state = Arc::clone(&state);
1260    let cert_tls = tls_states.clone();
1261    let cert_shutdown = shutdown_rx.clone();
1262    let cert_task = tokio::spawn(async move {
1263        let mut cert_rx = cert_rx;
1264        let mut shutting_down = cert_shutdown;
1265        loop {
1266            tokio::select! {
1267                maybe_event = cert_rx.recv() => {
1268                    let Some(()) = maybe_event else { break };
1269                    tokio::select! {
1270                        _ = tokio::time::sleep(RELOAD_DEBOUNCE) => {}
1271                        _ = shutting_down.changed() => return,
1272                    }
1273                    while cert_rx.try_recv().is_ok() {}
1274                    refresh_tls_states(&cert_state.snapshot(), &cert_tls, "cert-watch");
1275                }
1276                _ = shutting_down.changed() => return,
1277            }
1278        }
1279    });
1280
1281    // Signal waiter: SIGTERM/SIGINT stop accepting everywhere and unblock
1282    // main for the drain sequence.
1283    let signal_shutdown_tx = shutdown_tx.clone();
1284    tokio::spawn(async move {
1285        tokio::select! {
1286            _ = sigterm.recv() => tracing::info!("SIGTERM received, draining connections"),
1287            _ = sigint.recv() => tracing::info!("SIGINT received, draining connections"),
1288        }
1289        let _ = signal_shutdown_tx.send(());
1290    });
1291
1292    // DW-049: SIGUSR2 upgrade handler. On SIGUSR2 the old process spawns
1293    // a new binary (SO_REUSEPORT lets it bind alongside), waits for the
1294    // new process to signal READY, then triggers the SAME drain path as
1295    // SIGTERM — the new process is already accepting, so the drain has
1296    // zero refused connections and zero resets. A failed upgrade (timeout
1297    // or spawn error) logs and keeps the old process running.
1298    let upgrade_shutdown_tx = shutdown_tx.clone();
1299    tokio::spawn(async move {
1300        sigusr2.recv().await;
1301        match upgrade::initiate_upgrade(std::process::id()).await {
1302            Ok((_ready_listener, socket_path)) => {
1303                // The new process is accepting; clean up the ready socket
1304                // and trigger the drain. The ready listener is dropped
1305                // here (its socket file is removed below).
1306                let _ = std::fs::remove_file(&socket_path);
1307                let _ = upgrade_shutdown_tx.send(());
1308            }
1309            Err(_) => {
1310                // initiate_upgrade already logged the error; the old
1311                // process keeps running. Stay armed for a retry.
1312            }
1313        }
1314    });
1315
1316    // SCALE-03 (#182): TCP listener accept tasks are spawned by the
1317    // ListenerManager (above). H3 listener tasks are spawned separately
1318    // below. The per-listener shutdown watches cascade from the
1319    // process-wide shutdown watch via the manager.
1320
1321    // DW-088: Spawn H3 (QUIC) listener tasks. Each H3 listener runs its
1322    // own QUIC accept loop with the same shutdown signal.
1323    let mut h3_tasks = Vec::new();
1324    {
1325        for (listener, tls) in h3_listeners {
1326            let dp = Arc::clone(&dp);
1327            let rx = shutdown_rx.clone();
1328            h3_tasks.push(tokio::spawn(async move {
1329                if let Err(err) = h3::run_h3_listener(&listener, dp, tls, rx).await {
1330                    tracing::error!(
1331                        code = "h3_listener_failed",
1332                        listener = %listener.name,
1333                        "h3 listener ended: {err}"
1334                    );
1335                }
1336            }));
1337        }
1338    }
1339
1340    // DP-01 (#234): Spawn UDP L4 listener tasks. Each UDP listener
1341    // binds a UdpSocket and runs the UdpDispatcher recv loop.
1342    let mut udp_tasks = Vec::new();
1343    for listener in udp_listeners {
1344        let dp = Arc::clone(&dp);
1345        let state = Arc::clone(&state);
1346        let bind_addr = format!("{}:{}", listener.address, listener.port);
1347        // Validation guarantees UDP listeners have an `l4` block.
1348        let l4_cfg = listener
1349            .l4
1350            .clone()
1351            .expect("validated udp listener has l4 config");
1352        let l4_proxy = dwara_core::dataplane::l4::L4ProxyConfig::from_config(&l4_cfg);
1353        let dispatcher = dwara_core::dataplane::l4::UdpDispatcher::new(l4_proxy);
1354        let listener_name = listener.name.clone();
1355        udp_tasks.push(tokio::spawn(async move {
1356            let sock = match tokio::net::UdpSocket::bind(&bind_addr).await {
1357                Ok(s) => s,
1358                Err(e) => {
1359                    tracing::error!(
1360                        code = "udp_listener_bind_failed",
1361                        listener = %listener_name,
1362                        addr = %bind_addr,
1363                        "udp listener bind failed: {e}"
1364                    );
1365                    return;
1366                }
1367            };
1368            tracing::info!(
1369                code = "listening_udp",
1370                addr = %bind_addr,
1371                listener = %listener_name,
1372                "udp l4 listener bound"
1373            );
1374            let sock = Arc::new(sock);
1375            loop {
1376                let snapshot = state.snapshot();
1377                let gateway = snapshot.gateway();
1378                if let Err(err) = dispatcher.run(Arc::clone(&sock), &dp, gateway).await {
1379                    tracing::error!(
1380                        code = "udp_listener_failed",
1381                        listener = %listener_name,
1382                        "udp listener ended: {err}"
1383                    );
1384                    break;
1385                }
1386            }
1387        }));
1388    }
1389
1390    // DW-049: PID file + upgrade readiness. If this process is an upgrade
1391    // CHILD (DWARA_UPGRADE_READY_SOCKET set), it signals READY to the old
1392    // process AFTER it is accepting — the old process then drains and
1393    // exits. The PID file is written (or overwritten) AFTER the ready
1394    // signal so it always names the live acceptor: a normal start writes
1395    // it immediately (signal_ready is a no-op when the env is unset); an
1396    // upgrade child writes it once the hand-off is confirmed.
1397    upgrade::signal_ready().await;
1398    let pid = std::process::id();
1399    if let Ok(pid_file) = std::env::var("DWARA_PID_FILE") {
1400        if !pid_file.is_empty() {
1401            let path = PathBuf::from(&pid_file);
1402            if let Err(err) = upgrade::write_pid_file(&path, pid) {
1403                tracing::warn!(
1404                    code = "pid_file_write_failed",
1405                    path = %path.display(),
1406                    "cannot write PID file: {err}"
1407                );
1408            }
1409        }
1410    }
1411
1412    // Wait for the shutdown signal, then the per-listener backlog flushes.
1413    let mut main_shutdown = shutdown_rx.clone();
1414    let _ = main_shutdown.changed().await;
1415    let shutdown_deadline = tokio::time::Instant::now() + timeout;
1416    // SCALE-03 (#182): drain all TCP listener tasks via the manager.
1417    // H3 tasks are drained below via the h3_tasks Vec.
1418    {
1419        let mut lm = listener_manager.lock().await;
1420        lm.signal_all();
1421        lm.join_all().await;
1422    }
1423    // Drain H3 listener tasks.
1424    for t in h3_tasks {
1425        if let Err(err) = t.await {
1426            tracing::warn!("h3 listener task ended with an error: {err}");
1427        }
1428    }
1429    // Drain UDP L4 listener tasks.
1430    for t in udp_tasks {
1431        if let Err(err) = t.await {
1432            tracing::warn!("udp listener task ended with an error: {err}");
1433        }
1434    }
1435
1436    tracing::info!(
1437        live_connections = graceful.count(),
1438        in_flight_splices = splice_drain.in_flight(),
1439        timeout_s = timeout.as_secs(),
1440        "graceful shutdown"
1441    );
1442    reload_task.abort();
1443    let _ = reload_task.await;
1444    cert_task.abort();
1445    let _ = cert_task.await;
1446    webhook_task.abort();
1447    export_task.abort();
1448    // DW-054: the convergence task self-exits on the shutdown watch
1449    // (after a best-effort remove_instance); abort it here too so a
1450    // watch-miss cannot strand it past the drain window.
1451    if let Some(t) = convergence_task {
1452        t.abort();
1453    }
1454    if let Some(t) = &geoip_task {
1455        t.abort();
1456    }
1457    // DW-043: analytics workers are NOT aborted — the shutdown watch
1458    // tells the writer to drain, flush, and take a final rollup/retention
1459    // pass (a clean restart loses nothing); give them a bounded moment
1460    // inside the shutdown budget.
1461    for h in analytics_handles {
1462        let _ = tokio::time::timeout(std::time::Duration::from_secs(5), h).await;
1463    }
1464    // DW-121: the record-stream flusher drains the same way — its
1465    // shutdown handler flushes one final batch (bounded by the sink's
1466    // delivery timeout, and by this 5 s window whichever is shorter).
1467    let _ = tokio::time::timeout(std::time::Duration::from_secs(5), stream_task).await;
1468
1469    // Final drain within the shutdown budget; whatever is left when the
1470    // deadline passes is force-closed by process exit. The deadline is
1471    // measured from the shutdown signal (the accept tasks already spent
1472    // part of it flushing their backlogs). The HTTP graceful drain
1473    // (hyper) and the passthrough/L4 splice drain (#175, REL-04) run
1474    // concurrently over the same budget: both must complete before the
1475    // deadline for a clean exit; whichever is still running at the
1476    // deadline is force-closed by process exit.
1477    let deadline = shutdown_deadline;
1478    // SCALE-03 (#182): drop the ListenerManager so its Arc clones of
1479    // graceful/splice_drain/hardening are released before try_unwrap.
1480    drop(listener_manager);
1481    let graceful =
1482        Arc::try_unwrap(graceful).expect("all listener tasks joined; no Arc clones remain");
1483    let hyper_drain = graceful.shutdown();
1484    let splice_drain_for_drain = Arc::clone(&splice_drain);
1485    let drained = tokio::time::timeout_at(deadline, async {
1486        let splice_fut = splice_drain_for_drain.drain(deadline);
1487        let (_, splices_drained) = tokio::join!(hyper_drain, splice_fut);
1488        splices_drained
1489    })
1490    .await
1491    .unwrap_or_default();
1492    if !drained {
1493        tracing::warn!(
1494            in_flight_splices = splice_drain.in_flight(),
1495            "shutdown timeout with connection(s) still draining; forcing exit"
1496        );
1497    } else {
1498        tracing::info!("drained, exiting");
1499    }
1500
1501    // #126: OTLP flush on the shutdown path — the exporter drains its
1502    // batch and posts the remaining spans, bounded by whatever is left
1503    // of the drain budget (the SDK caps itself at 5s). Feature OFF or
1504    // endpoint unset = nothing here.
1505    otlp.shutdown(deadline.saturating_duration_since(tokio::time::Instant::now()))
1506        .await;
1507
1508    // DW-073: OTLP metrics exporter shutdown — signal the periodic task
1509    // to stop and perform a final flush.
1510    if let Some(metrics) = otlp_metrics {
1511        metrics.shutdown();
1512    }
1513
1514    std::process::exit(0);
1515}

1553/// Establish a pooled Redis connection for the distributed rate limiter
1554/// (DW-031, ent feature only). The connection is established once at
1555/// startup with the configured timeout and cloned cheaply per rule at
1556/// engine compile time. Returns a `ConnectionManager` (multiplexed,
1557/// auto-reconnecting) on success.
1558#[cfg(feature = "ent")]
1559async fn establish_redis_connection(
1560    config: &dwara_core::config::RedisRateLimiterConfig,
1561) -> Result<redis::aio::ConnectionManager, Box<dyn std::error::Error + Send + Sync>> {
1562    use dwara_core::config::RedisTopology;
1563    let timeout = Duration::from_millis(config.connection_timeout_ms);
1564    match config.ha.topology {
1565        RedisTopology::Single => {
1566            let client = redis::Client::open(config.url.as_str())?;
1567            let conn = tokio::time::timeout(timeout, client.get_connection_manager()).await??;
1568            Ok(conn)
1569        }
1570        RedisTopology::Sentinel => {
1571            // SCALE-11 (#248): Sentinel mode. Resolve the master via
1572            // SENTINEL GET-MASTER-ADDR-BY-NAME, then connect to the
1573            // resolved master with a ConnectionManager (auto-reconnecting
1574            // on failover is handled by re-resolving on disconnect).
1575            let master_name =
1576                config.ha.master_name.as_deref().ok_or(
1577                    "redis_rate_limiter.ha.master_name is required when topology = sentinel",
1578                )?;
1579            let sentinel_urls: Vec<String> = if config.ha.nodes.is_empty() {
1580                vec![config.url.clone()]
1581            } else {
1582                config.ha.nodes.clone()
1583            };
1584            // Try each Sentinel node until one responds with the master
1585            // address. Sentinels are interchangeable; any one can
1586            // resolve the master.
1587            let mut master_url: Option<String> = None;
1588            for sentinel_url in &sentinel_urls {
1589                let sentinel_client = redis::Client::open(sentinel_url.as_str())?;
1590                let mut sentinel_conn = match tokio::time::timeout(
1591                    timeout,
1592                    sentinel_client.get_multiplexed_async_connection(),
1593                )
1594                .await
1595                {
1596                    Ok(Ok(conn)) => conn,
1597                    Ok(Err(_)) | Err(_) => continue,
1598                };
1599                let addr: (String, String) = match redis::cmd("SENTINEL")
1600                    .arg("GET-MASTER-ADDR-BY-NAME")
1601                    .arg(master_name)
1602                    .query_async(&mut sentinel_conn)
1603                    .await
1604                {
1605                    Ok(addr) => addr,
1606                    Err(_) => continue,
1607                };
1608                master_url = Some(format!("redis://{}/{}", addr.0, addr.1));
1609                break;
1610            }
1611            let master_url = master_url.ok_or(format!(
1612                "failed to resolve master '{master_name}' from any Sentinel node"
1613            ))?;
1614            tracing::info!(
1615                code = "redis_sentinel_master_resolved",
1616                master_name = master_name,
1617                master_url = %master_url,
1618                "Sentinel resolved master for redis_rate_limiter"
1619            );
1620            let client = redis::Client::open(master_url.as_str())?;
1621            let conn = tokio::time::timeout(timeout, client.get_connection_manager()).await??;
1622            Ok(conn)
1623        }
1624        RedisTopology::Cluster => {
1625            // SCALE-11 (#248): Redis Cluster mode. The redis 0.27
1626            // crate's async cluster connection (ClusterConnection) is
1627            // not Send (uses RefCell internally), so it cannot be used
1628            // with ConnectionManager. Instead, connect to the first
1629            // cluster node with a ConnectionManager. The rate limiter
1630            // uses hash tags ({key}) to ensure all windows for one
1631            // logical key land on the same slot; if the connected node
1632            // is not the owner of that slot, Redis returns a MOVED
1633            // error which is treated as a backend error (fail-open or
1634            // fail-closed per config). Full cluster support with
1635            // automatic MOVED/ASK handling is a future enhancement
1636            // (requires upgrading to a redis crate version with a
1637            // Send async cluster connection).
1638            let cluster_url = config.ha.nodes.first().unwrap_or(&config.url);
1639            let client = redis::Client::open(cluster_url.as_str())?;
1640            let conn = tokio::time::timeout(timeout, client.get_connection_manager()).await??;
1641            Ok(conn)
1642        }
1643    }
1644}

1675/// Build the config convergence coordinator (DW-054, ent feature only).
1676/// Establishes a Redis connection (reusing the DW-031 connection helper
1677/// shape), builds the `RedisConvergenceBackend` over it, and constructs
1678/// the `ConvergenceCoordinator` with a per-process instance id. The
1679/// coordinator is returned for the caller to attach to the dataplane
1680/// and spawn against the shutdown watch.
1681#[cfg(feature = "ent")]
1682async fn build_convergence_coordinator(
1683    config: &dwara_core::config::ConfigConvergenceConfig,
1684    state: Arc<dwara_core::snapshot::ConfigState>,
1685    obs: Arc<dwara_core::observability::Observability>,
1686) -> Result<
1687    Arc<dwara_core::dataplane::convergence::ConvergenceCoordinator>,
1688    Box<dyn std::error::Error + Send + Sync>,
1689> {
1690    use dwara_core::dataplane::convergence::ConvergenceCoordinator;
1691    use dwara_core::extensions::config_convergence::{
1692        ConfigConvergenceBackend, RedisConvergenceBackend,
1693    };
1694
1695    let url = config
1696        .redis_url
1697        .as_deref()
1698        .ok_or("config_convergence.redis_url is required when backend = 'redis'")?;
1699    let client = redis::Client::open(url)?;
1700    // The convergence backend reuses the DW-031 connection timeout
1701    // bound (100..=30000 ms); the config block does not carry its own
1702    // timeout, so the default startup timeout applies.
1703    let conn = tokio::time::timeout(
1704        Duration::from_millis(dwara_core::config::limits::MAX_REDIS_CONNECTION_TIMEOUT_MS / 3),
1705        client.get_connection_manager(),
1706    )
1707    .await??;
1708    // TTLs: instances hash expires after 3x the poll interval (a
1709    // healthy instance refreshes it each cycle, so 3x is a generous
1710    // miss margin); config bodies live for 1 hour (a slow instance
1711    // converging well past the poll interval still finds the body).
1712    let instances_ttl_s = (config.poll_interval_ms / 1000).max(1) * 3;
1713    let config_ttl_s = 3600;
1714    let backend = Arc::new(RedisConvergenceBackend::new(
1715        conn,
1716        config.key_prefix.clone(),
1717        instances_ttl_s,
1718        config_ttl_s,
1719    )) as Arc<dyn ConfigConvergenceBackend>;
1720    // Instance id: DWARA_INSTANCE_ID overrides; otherwise derive from
1721    // pid + a startup timestamp so two processes on one host differ.
1722    let instance_id = std::env::var("DWARA_INSTANCE_ID")
1723        .ok()
1724        .filter(|s| !s.is_empty())
1725        .unwrap_or_else(|| {
1726            let ts = std::time::SystemTime::now()
1727                .duration_since(std::time::UNIX_EPOCH)
1728                .map(|d| d.as_millis())
1729                .unwrap_or(0);
1730            format!("{}-{}", std::process::id(), ts)
1731        });
1732    Ok(Arc::new(ConvergenceCoordinator::new(
1733        state,
1734        backend,
1735        obs,
1736        instance_id,
1737        config.poll_interval_ms,
1738        config.drift_check_interval_ms,
1739        config.fail_open,
1740    )))
1741}

1750/// Build the enterprise license gate from the config's `license` block
1751/// (DW-032). Returns a `LicenseGate` reflecting the verification
1752/// outcome. Startup behavior:
1753///
1754/// - No `license` block: OSS mode, logs "running in OSS mode".
1755/// - `license` block + valid: enterprise mode, logs customer/plan/features.
1756/// - `license` block + expired + within grace: enterprise mode, warns.
1757/// - `license` block + expired + past grace: degrades to OSS, logs.
1758/// - `license` block + invalid signature: refuses to start (exit 1).
1759/// - `license` block + file not found: refuses to start (exit 1).
1760///
1761/// When the `ent` cargo feature is NOT compiled in, the block is
1762/// accepted but inert (the gate is always `none()`); a present block
1763/// logs a one-line notice that the ent feature is not compiled in.
1764fn build_license_gate(
1765    gateway: &dwara_core::config::Gateway,
1766) -> dwara_core::extensions::licensing::LicenseGate {
1767    use dwara_core::extensions::licensing::LicenseGate;
1768
1769    let Some(lic_cfg) = &gateway.license else {
1770        tracing::info!(
1771            code = "license_oss_mode",
1772            "running in OSS mode (no license configured)"
1773        );
1774        return LicenseGate::none();
1775    };
1776
1777    #[cfg(not(feature = "ent"))]
1778    {
1779        tracing::info!(
1780            code = "license_block_inert",
1781            file = %lic_cfg.file,
1782            "license block present but the ent cargo feature is not compiled in; \
1783             running in OSS mode (the block is accepted but inert)"
1784        );
1785        LicenseGate::none()
1786    }
1787
1788    #[cfg(feature = "ent")]
1789    {
1790        use dwara_core::extensions::licensing::LicenseStatus;
1791        let grace = lic_cfg.grace_period_days;
1792        match LicenseGate::from_file(std::path::Path::new(&lic_cfg.file), grace) {
1793            Ok(gate) => {
1794                match gate.status() {
1795                    LicenseStatus::Valid => {
1796                        tracing::info!(
1797                            code = "license_verified",
1798                            customer = gate.customer().unwrap_or("?"),
1799                            plan = gate.plan().unwrap_or("?"),
1800                            features = ?gate.features(),
1801                            "enterprise license verified: customer={}, plan={}, features={:?}",
1802                            gate.customer().unwrap_or("?"),
1803                            gate.plan().unwrap_or("?"),
1804                            gate.features(),
1805                        );
1806                    }
1807                    LicenseStatus::ExpiredWithinGrace => {
1808                        tracing::warn!(
1809                            code = "license_expired_within_grace",
1810                            expires_at = gate.expires_at().as_deref().unwrap_or("?"),
1811                            grace_period_days = grace,
1812                            "license expired but within grace period (expires_at={}); \
1813                             enterprise features still active — renew before the grace window ends",
1814                            gate.expires_at().as_deref().unwrap_or("?"),
1815                        );
1816                    }
1817                    LicenseStatus::ExpiredPastGrace => {
1818                        tracing::warn!(
1819                            code = "license_expired_past_grace",
1820                            "license expired past grace period, degrading to OSS"
1821                        );
1822                    }
1823                    LicenseStatus::NoLicense => {
1824                        // Unreachable: from_file always sets a status
1825                        // when it returns Ok. Defensive log.
1826                        tracing::warn!(
1827                            code = "license_unexpected_status",
1828                            "license gate returned no-license status after from_file"
1829                        );
1830                    }
1831                }
1832                gate
1833            }
1834            Err(err) => {
1835                tracing::error!(
1836                    code = "license_load_failed",
1837                    "license verification failed: {err}; refusing to start"
1838                );
1839                std::process::exit(1);
1840            }
1841        }
1842    }
1843}
