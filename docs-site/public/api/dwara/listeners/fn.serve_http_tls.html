Serve one (possibly TLS-terminated) connection with the proxy dataplane. Upgrades are enabled on the inbound connection so WebSocket-style 101 tunnels can be spliced (generic tunneling; see dwara-core’s proxy docs). client_cert is the VERIFIED client certificate when the TLS layer requested one (#124); it rides the request extensions to the authenticator’s ambient mTLS family.
