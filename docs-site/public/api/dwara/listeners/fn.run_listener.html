Per-listener accept loop with its own backlog flush (the DW-006 drain sequence, per listener). Returns when shutdown is signalled and the backlog is flushed. Takes the socket behind an Arc shared with the panic supervisor (#120): a respawned incarnation accepts on the SAME bound socket instead of re-binding (no port-loss window, no bind race with lingering state).
