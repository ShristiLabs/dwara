Expand description

Build the enterprise license gate from the config’s license block (DW-032). Returns a LicenseGate reflecting the verification outcome. Startup behavior:

  • No license block: OSS mode, logs “running in OSS mode”.
  • license block + valid: enterprise mode, logs customer/plan/features.
  • license block + expired + within grace: enterprise mode, warns.
  • license block + expired + past grace: degrades to OSS, logs.
  • license block + invalid signature: refuses to start (exit 1).
  • license block + file not found: refuses to start (exit 1).

When the ent cargo feature is NOT compiled in, the block is accepted but inert (the gate is always none()); a present block logs a one-line notice that the ent feature is not compiled in.
