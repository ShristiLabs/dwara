Minimal IP/CIDR support for trusted-proxy and IP-ACL matching (DW-009/DW-020).

The trusted-proxy matcher is part of the CONFIG CONTRACT — validation (snapshot::validate) and every runtime consumer (the dataplane’s forwarded-header rule, authorization’s IP ACLs) must agree on what a well-formed ip/ip/prefix entry is, so the parser and the matcher live here with the schema instead of in any one consumer. No new dependency: std::net parsing plus a shift-compare.
