pub fn resolve_includes(text: &str, base_dir: &Path) -> Result<String, String>
Expand description

Resolve includes: directives in a config document. The includes: top-level key lists file paths or directory globs (relative to base_dir). Each is read, recursively resolved, and merged into the base. The includes: key is removed from the result. Returns the merged YAML text.
