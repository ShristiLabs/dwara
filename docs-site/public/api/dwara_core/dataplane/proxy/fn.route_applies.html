Expand description

Apply the route’s non-path criteria. All criteria are AND-ed. Empty method list = all methods; host matches the Host header (case-insensitive, with or without a port); headers must all be present with exact values; query and cookie entries match on presence, or on exact value when one is configured. accept is the route’s COMPILED match.accept media type (RouteTable::accept_media_type), never the raw config string — padding and case are normalized once at snapshot compile, so a padded spelling matches exactly like its trimmed form. Public so router golden-file tests (tests/router_golden.rs) can exercise the full resolution pipeline without a live upstream.
