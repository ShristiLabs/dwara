Expand description

Wrap a single gRPC data chunk in a gRPC-Web data frame (no trailer frame). Used for streaming responses where each upstream data frame becomes its own gRPC-Web data frame, and the trailer frame is sent once at stream end via translate_grpc_trailers_to_grpc_web.
