Expand description

Send an HTTP/3 request over a QUIC stream (one send_request call = one bidirectional stream) and read the full response. The request body is sent as a single DATA frame (the H3 path buffers the request body; see the module docs); the response body is collected into one [Bytes] (streaming H3 response bodies are a follow-up).

send_request is taken by mutable reference because h3’s send_request requires &mut self; the caller clones it from the pool so the pooled connection itself is not borrowed.
