pub fn read_cookie(headers: &HeaderMap, name: &str) -> Option<String>
Expand description

Read one cookie’s value from a request’s Cookie headers (the first match across all header lines wins; Cookie is a semicolon-separated name=value list per RFC 6265). Returns the trimmed value; a malformed pair cannot match a validated cookie name and is skipped silently (the gateway then mints a fresh handle — the safe direction: a bad cookie re-sessions rather than mis-routing).
