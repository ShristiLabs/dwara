Expand description

The per-instance context the host imports read from and write to.

Stored as the wasmtime store’s T type. The host import functions receive a &mut PluginContext via Caller and use it to exchange data with the plugin.

§action: u32

The action the plugin returned from the last phase callback.

§local_response: Option<LocalResponse>

Whether the plugin has called proxy_send_http_response (a short-circuit response). When set, the host should stop processing and return the stored response.

§logs: Vec<(u32, String)>

Log lines emitted by the plugin via proxy_log.

§shared_data: Arc<Mutex<SharedData>>

The VM-scoped shared-data store handle (see SharedData).

§pending_callouts: Vec<PendingCallout>

Callouts registered by proxy_http_call and not yet answered (DW-167). One instance can queue several; the dispatch driver performs them in FIFO order, one round each.

§callout_token_counter: u32

Monotonic callout-token counter (tokens are handed out by the host and delivered back with proxy_on_http_call_response).

§callout_response_headers: Vec<(String, String)>

The last delivered callout response’s header map (:status plus ordinary headers, hop-by-hop stripped) — what MapType 6 reads return inside proxy_on_http_call_response.

§callout_response_body: Vec<u8>

The last delivered callout response’s body — what BufferType 4 reads return inside proxy_on_http_call_response.

§metrics: HashMap<String, PluginMetric>

Metrics registered by the plugin.

§current_context_id: u32

The current context ID (set by the host before calling exports).

§effective_context_id: u32

The effective context ID (set by proxy_set_effective_context).

§done: bool

Whether proxy_done was called.

§memory_used: usize

Memory limiter state (tracks current allocation against the cap).

§memory_cap: usize

Memory cap in bytes.
