Perform one callout exchange. Synchronous by design (the async boundary is plugin_dispatch’s spawn_blocking); reuses the registry fetcher’s transport posture (SSRF at connect, per-read timeouts clamped to the deadline, Connection: close, read to EOF) with the http:// scheme and arbitrary methods added.
