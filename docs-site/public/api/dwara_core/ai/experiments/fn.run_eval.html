Run an eval against a model alias (DW-086). The provider_url is the full URL, auth_header is the optional Authorization header, provider_model is the provider’s own model identifier, and system_message is the optional prompt-version system message (from the eval’s prompt reference, resolved by the caller). Returns the per-case results.
