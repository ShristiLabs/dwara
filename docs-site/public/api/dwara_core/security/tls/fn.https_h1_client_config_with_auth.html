SEC-03: HTTP/1.1-ALPN rustls client config WITH client auth (mTLS to the upstream). Loads the client cert chain and private key from PEM files and installs them via with_client_auth_cert. Used when an upstream configures mtls.client_cert_file + mtls.client_key_file. Fails with TlsError::Io when the files cannot be read or parsed.
